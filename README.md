- index.html — Home

## Central navigation

The navigation is generated by `nav.js`. To add or remove a site-wide navigation link, edit the single list inside `nav.js`; do not manually edit every HTML page. Keep `<nav id="site-nav" class="site-nav" aria-label="Main navigation"></nav>` and `<script src="nav.js" defer></script>` on each page so the shared navigation works. The mobile menu and current-page highlight are handled by this script.

## Adding a new course module

1. Copy `module-template.html` and rename it (for example, `module5.html`).
2. Replace the bracketed placeholders with your assignment content and update the page title and description.
3. Open `modules.html` and copy a module card. Change the title, summary, skills, and link to your new page.
4. Upload the new HTML page and updated `modules.html` to GitHub. You do **not** need to edit `nav.js` for each new module because the main navigation already links to the Modules directory.
5. Check the page on your phone and in a private browser window.

`module-template.html` is a starter file; do not add it as a published module card. The actual published modules are listed in `modules.html`.


## Central dropdown navigation

The main navigation is controlled by `nav.js`. The website displays one Menu button at the top; clicking it opens the links. To add or remove a navigation item, edit the `pages` list in `nav.js` only. Keep `nav.js` and `styles.css` in the same folder as the HTML pages.
